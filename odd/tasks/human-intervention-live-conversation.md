# Human intervention — live conversation (backend unit 11)

The bot goes silent while a person attends the customer, relays staff messages (text, images, PDFs, templates) to WhatsApp, announces start / reassignment / end, and lets the customer ask for a person ("quiero hablar con una persona").
Contract: houndfe-backend `docs/chatbot-handoff/chatbot-requests-bot-contract.md` §"Live conversation (unit 11)" (commit 5b1ce241). Branch: `feat/live-conversation`.

## Specs

- **S1 — Owner directives (unit 9 L1, still binding):** "siempre teniendo como prioridad la performance del sistema … todo lo que tenemos localmente es DESECHABLE".
- **S2 — Silence protocol (contract rules 1–10, final):** (1) `started` with epoch N > ours: one durable compare-and-set to `{HUMAN, N, requestId}`, then session-ack STARTED, and only after a 200 the greeting, then the outcome; 409 → no greeting; N ≤ ours → STALE, no ack. (2) While HUMAN, total silence (no audio prompt, no overdue notice, no answered/cancelled: `DEFERRED_HUMAN_SESSION` if the item may wait, `STALE` otherwise). (3) Customer messages mirrored IN only. (4) Staff text sent verbatim, no prefix; epoch mismatch → STALE; dedupe by deliveryId and messageId stored before calling Meta. (5) `seq` order, gap hold ≤30 s (advisory). (6) `ended` with N ≥ ours: durable BOT (keep epoch), farewell only if `farewell` and window open, outcome, session-ack ENDED, then replay pending-deliveries `HUMAN_SESSION`; ours > N → STALE, no ack. (7) START_TIMEOUT: BOT, send nothing, STALE, no ack; if `resumeNotice` and a greeting actually went out, send the resume text. (8) Safety notice once per epoch, only if the feed has been down >10 min and the window is open; a restart does not repeat it. (9) Reconcile with GET state at start-up and every 5 min while muted (bulk `?mode=HUMAN`; `messages:batch` returns `{mode, handoffEpoch}` as a hint); backend wins; missed ended → rule 6 with farewell=false; missed started → mute, no greeting, session-ack STARTED. (10) Never ACK staff_message/template STALE for a conversation actually muted.
- **S3 — Routes and items (contract):** session-ack `POST /chatbot-api/conversations/:ref/session-ack {epoch, state, providerMessageId?}` (control bucket 120/min; 409 STALE_EPOCH / SESSION_NOT_ENDING → reconcile, never retry); GET state single and bulk; `GET /chatbot-api/media/:id` (scope media:read; 404 → STALE); items `conversation.started`, `conversation.staff_message` (TEXT | IMAGE | DOCUMENT with mediaId, mimeType, filename, caption), `template.requested` (templateName, languageCode default es_MX, no variables; retry only after a definite FAILED, UNKNOWN blocks), `conversation.reassigned` (staffFirstName), `conversation.ended` (reason FINISHED | FORCED | IDLE_TIMEOUT | START_TIMEOUT, farewell, resumeNotice). ACK matrix: started/reassigned/ended/template → PROVIDER_ACCEPTED | DELIVERY_UNKNOWN | STALE; staff_message → also DEFERRED_WINDOW_CLOSED; never DEFERRED_HUMAN_SESSION. 131047 on a staff message = window closed; deferred staff items become FAILED at epoch end (resend → 409 OUTCOME_ALREADY_RECORDED = not coming).
- **S4 — Mirror (contract):** never mirror staff messages or templates (report the wamid only in the outcome); greeting, farewell, reassignment and resume notices are BOT messages (mirrored); bot turns in flight at claim time are mirrored as usual.
- **S5 — Approved customer texts (owner, 2026-11-12, usted; tú derived by the existing styling):** greeting «Le atiende {nombre} del equipo HoundFe.» / no name «Le atiende una persona del equipo HoundFe.»; reassignment «Ahora le atiende {nombre}, del equipo HoundFe.» / no name «Ahora le atiende otra persona del equipo HoundFe.»; end (normal and 2 h idle) «Listo, terminó la atención con el equipo. Si necesita algo más, aquí sigo para ayudarle.»; resume after a reverted start «Seguimos por aquí, ¿en qué le ayudo?»; talk-to-human created «Con gusto, ya le pedí a una persona del equipo que le atienda. En cuanto alguien esté disponible, le escribe por aquí.»; out of hours «Nuestro equipo atiende de lunes a sábado de 9 a 19 h. Ya dejé su solicitud y le escriben en cuanto abramos.»; safety notice «Tenemos una falla técnica, en cuanto se resuelva le respondemos.»
- **S6 — Talk to a person (owner):** "Directo, con esos textos" — when the customer clearly asks for a person, create a TALK_TO_HUMAN request without asking first. Scheduling a slot stays for phase 7 (design doc).
- **S7 — No phone in logs** (unit 9 S6, `src/common/log-safe.ts`).
- **S8 — E2E with the backend on dev** once unit 11 is deployed there (credential adds `media:read`).
